# Paradise Nursery Shopping Application

## Project Name
**Paradise Nursery**

## Description
Paradise Nursery is a React-based e-commerce web application designed for plant lovers. It allows users to explore a wide variety of indoor and air-purifying plants, view detailed descriptions and prices, manage a shopping cart (add items, update quantities, remove items), and experience a seamless plant-shopping journey starting from an engaging landing page.

## Features
- **Landing Page**: Features a welcoming background image, company name, a brief introduction, and a "Get Started" button.
- **About Us Section**: Provides information about the company's mission and passion for green living.
- **Product Listing**: Displays plants categorized by their types (e.g., Air Purifying, Aromatic) with images, names, prices, and dynamic "Add to Cart" state.
- **Shopping Cart Management**: Powered by Redux Toolkit, allowing users to:
  - View all selected plants with total cost calculation.
  - Increment or decrement plant quantities (`updateQuantity`).
  - Remove items from the cart (`removeItem`).
  - Add new items (`addItem`).

## Technologies Used
- **React.js** (Functional Components, Hooks, State Management)
- **Redux Toolkit** (Global State Management for Shopping Cart)
- **CSS3** (Responsive styling and landing page background implementation)
